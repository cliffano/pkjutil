    upgradeDependencies(optsopt, cb)

    Upgrade the version of each dependency to the latest published in the registry. Version range will be kept, e.g. ~0.0.1 is upgraded to ~0.0.18 . If version does not contain numeric major.minor.patch, then version is upgraded to latest, e.g. 0.0.x is upgraded to 0.0.18 .
